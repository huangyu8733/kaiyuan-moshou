## 修复：DotA 选变体精灵（Morphling）出生即死、血量恒为 0

**根因**：地图在英雄售出后给英雄塞隐藏道具 `I00E`（名为 "Morphling BUG Reparar"，powerup / uses=1），其能力 `A0GN` 的 base code 是 `AImi`（生命手册），`DataA1 = -2000`。引擎 `applyItemAbility` 的 `AImi` 分支直接 `baseMaxHp += d(0)`，把 480 写成 -1520；上限 < 1 → 当帧 `tickBuffs → kill`，复活时 `heroReviveVitals` 仍按 ≤0 的上限算血，于是永远 0 血。真 WC3 对负数 `AImi` 是空操作，地图正是拿它当"修 bug 占位"道具。

**测试**：`tools/sim-item-test.cjs` 新增用例（生命手册 +100 生效、-2000 无效且不掉上限/不掉血），`AImiN`/`AImi` 双 ability 桩。
